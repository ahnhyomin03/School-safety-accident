# 무릎 사고 외부자료 조사 문서

이 폴더의 분석은 대회 중앙회 제공 원자료와 분리해서 진행한다.

## 데이터 취급 원칙

- 중앙회 제공 사고·보상 원자료 및 그 전처리본은 이 폴더의 스크립트에서 읽지 않는다.
- 외부 공개자료가 큰 경우 별도 Python 스크립트로 분석한다.
- 중앙회 자료와 비교가 필요하면 참가팀이 내부 환경에서 만든 **집계표**만 사용한다.
- 집계표에는 개인 식별 가능 정보와 개별 사고 행을 포함하지 않는다.

## 파일

- `무릎사고_외부데이터_분석설계.md`: 비교 설계, 활용 가능한 공공·공개자료, 해석상 주의점
- `2024_외부공개자료_축구분석결과.md`: 연령·선수 유형별 축구 부상과 예방행동 집계 결과
- `analyze_external_sports.py`: 스포츠안전재단 2024 공개 원자료 중 축구 응답을 집계하는 스크립트
- `data/2024_스포츠안전사고_실태조사_체육인_raw.xlsx`: 스포츠안전재단 외부 공개자료
- `data/2024_스포츠안전사고_공개자료_축구분석.json`: 위 스크립트의 집계 결과

## 팀이 내부에서 만들어 줄 최소 집계표

중앙회 원자료를 외부 서비스에 전달하지 않고, 아래 항목만 표 형태로 산출한다.

| 연도 | 학교급 | 사고 당시 활동 | 사고 부위 | 사고 건수 |
|---|---|---|---|---:|

가능하면 다음 보조표도 만든다.

| 연도 | 학교급 | 사고 당시 활동 | 사고 형태 또는 원인 | 사고 건수 |
|---|---|---|---|---:|

축구 비교 시에는 활동명을 축구로 제한한 뒤, 무릎·발목·손가락 등 부위별 건수와 전체 축구 사고 건수를 함께 제공해야 한다.
